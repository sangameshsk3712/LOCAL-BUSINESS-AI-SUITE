## 🌟 Executive Overview

## ⚡ Core Platform Capabilities

### 1. 📍 Geo-Grid Hyper-Local SEO Radar
- 3x3 / 5x5 geographical coordinate scanning across target postal codes and competitor perimeters.
- Real-time Google Business Profile ranking simulator with visual heatmap diagnostics.
- AI-generated action plan for Google Maps top-3 ranking optimization.

### 2. 📱 Google Play Console Publishing Hub & Android TWA
- **Pre-Flight Store Readiness Audit**: Automated 5-point compliance check for Manifest, Service Worker, Viewport, and HTTPS.
- **Trusted Web Activity (TWA) Builder**: Packaged under `com.localbiz.ai.twa` with digital asset link (`assetlinks.json`) validation.
- **Store Listing Generator**: Formatted title, short description (<80 chars), and rich keyword-optimized full description.
- **Visual Graphics Studio**: Live 1024x500 Feature Graphic Generator with one-click PNG download & 512x512 adaptive icon asset exporter.
- **Full Privacy Policy**: Pre-hosted endpoint at `/privacy-policy` fulfilling Google Play Console requirements.

### 3. 💬 WhatsApp Business Automated Growth Engine
- Instant personalized offer and campaign generation formatted with bolding, emojis, and urgency triggers.
- Click-to-chat deep link integration (`wa.me`) for instant broadcasts to customer phone lists.
- Abandoned cart & VIP loyalty re-engagement workflows.

### 4. 🎙️ AI Voice Receptionist & Audio Transcriber
- Converts recorded customer calls, voicemails, or walk-in inquiries into structured CRM leads.
- Automatically extracts customer name, intent, budget, urgency, and recommended follow-up actions.

### 5. 🏢 Franchise Command Center & Multi-Tenant RBAC
- Enterprise dashboard for multi-store operators (Store Managers, Regional Directors, Franchise Admins).
- Centralized royalty tracking, store health scorecards, and cross-location marketing sync.

### 6. 💼 ₹100 Crore Enterprise Acquisition & Due Diligence Deck
- Live valuation engine, Unit Economics model, and ARR growth trajectory built for strategic acquirers.
- Cap table preview, technical audit badges, and founder contact channels.

### 7. 💳 Monetization & Pro Licensing Engine
- In-app payment activation workflows supporting UPI (FamPay), Card, and Net Banking.
- Unique cryptographic Pro Activation Code verification engine with zero bypass security.

### 8. 🔐 Firebase User Authentication & Cross-Session Work History
- **Multi-Role Merchant Login**: Supports Email/Password authentication, 1-click Instant Guest mode, and fast Demo profiles.
- **Cross-Session Persistence**: Automatically captures and stores every generated marketing plan, code widget, SEO teardown, and financial model into Firebase Firestore.
- **Unified History Hub**: Browse, search, filter by module, re-copy prompts, star favorites, and export entire history to JSON anytime.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js 18+ or 20+
- npm or bun

### 1. Clone & Install
```bash
git clone https://github.com/sangameshsk3712/LOCAL-BUSINESS-AI-SUITE.git
cd LOCAL-BUSINESS-AI-SUITE
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env
```
Provide your Gemini API key in `.env`:
```env
GEMINI_API_KEY="your-gemini-api-key"
PORT=3000
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
npm start
```

---

## 📱 Publishing to Google Play Store (TWA)

1. Open the application and navigate to **Google Play Store Hub** in the sidebar.
2. Review the automated **Pre-Flight Readiness Scorecard**.
3. In the **Graphics Studio**, click **Download 1024×500 Feature Graphic** and **Download 512×512 Icon**.
4. In the **Store Copy** tab, copy the pre-formatted App Title and Descriptions.
5. In the **TWA & APK** tab, click **Open in PWABuilder** or run Bubblewrap CLI to export your signed `.aab`.
6. Upload the `.aab` to your [Google Play Console](https://play.google.com/console).
